# Contributing

Start with the [development guide](docs/DEVELOPMENT.md) for setup, focused checks,
component responsibilities and the public-source boundary. Use the
[documentation index](docs/README.md) to find the contract for your change.

Explain the problem, the resulting behavior and how you checked it. Distinguish
source tests from physical Deck behavior. Keep documentation in UTF-8 Markdown
or plain text, and preserve existing licenses and dated evidence.

Report a reproducible problem in [Issues](https://github.com/trynottopanic/HGttG_vol1/issues),
or open a pull request with a focused change. Do not include credentials, private
owner data, captures or generated system images.
