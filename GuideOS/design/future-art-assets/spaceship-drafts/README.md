# GuideOS Spaceship Draft Set

These nine transparent PNGs are approved **experimental prototypes**. They are
enlarged design drafts intended for silhouette, palette, and motion planning
before any design is reduced, cleaned, and redrawn as a production 32x32
animation sprite.

## Files

- `beetle-salvage-tug-draft.png`
- `needle-courier-draft.png`
- `lantern-survey-craft-draft.png`
- `mule-cargo-carrier-draft.png`

- `heron-reconnaissance-ship-draft.png`
- `jackrabbit-racing-craft-draft.png`

## Simplified experimental prototypes

The first silhouette-reduction pass is stored separately from the detailed
concept art:

- `beetle-simplified-prototype-v1.png`
- `needle-simplified-prototype-v1.png`
- `lantern-simplified-prototype-v1.png`

These versions remove minor paneling and machinery while preserving the major
shape, palette, windows, engines, and signature external components. They are
design references for the eventual hand-authored 32x32 sprites; they are not
the final 32x32 runtime files.

## Shared generation specification

- Original detailed pixel-art spacecraft.
- Elaborate late-16-bit / later-SNES visual treatment.
- Worn, practical retro-futurism with readable damage, repairs, panels and
  exposed machinery.
- One centered ship on a genuinely transparent background.
- Strong silhouette suitable for later reduction to a 32x32 sprite.
- Deliberate square pixels without smoothing or antialiasing.
- No text, labels, logos, watermarks, photorealism or background scenery.
- No close resemblance to an existing fictional spacecraft.

Each individual prompt supplied the corresponding ship description from the
nine-design concept list: Beetle, Needle, Lantern, Mule, Manta, Kettle, Heron,
Jackrabbit, and Hearth.

## Production boundary

Experimental-prototype approval does not make these final runtime assets.
Directly shrinking them to 32x32 will destroy important forms. Each design must
instead be manually simplified and redrawn at target resolution, with
animation-specific silhouette, palette, and readability checks. See
`IDLE_ANIMATION_PLAN.md` for the first motion specification.
