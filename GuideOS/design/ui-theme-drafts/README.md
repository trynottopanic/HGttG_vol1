# UI theme draft catalogue

This directory contains 38 PNG visual references, each 1448 by 1086 pixels.
The records below describe their design context and approval status. These
are visual references; current behavior is described in the component contracts
and implementation records.

## References with retained design records

The seven Field Theme files below also appear byte-for-byte in the
[approved visual-direction handoff](../handoff/field-theme-1/README.md).
The handoff describes their historical design direction. Component contracts
and later implementation records govern the current interface.

The three Notepad files are the first fixtures named in the
[accepted Notepad specification](../../NOTEPAD_CARTRIDGE_0.md) and its
[integration reconciliation](../../docs/NOTEPAD_INSTALLATION_INTEGRATION_0.md).
They precede the separately recorded
[3 October Notepad drafts](../notepad-drafts/2026-10-03-v1/README.md) and
[implementation](../../docs/NOTEPAD_UI_IMPLEMENTATION_2026_10_03.md).
The Storage draft has its own adopted presentation contract.
