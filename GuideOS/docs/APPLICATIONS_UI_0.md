# Applications UI 0

Status: approved present-runtime landing direction, 27 September 2026. This is a
presentation contract only; it does not assert that a displayed application is
installed, or that this interface is implemented in the current Seed.

The current Applications landing uses a small number of large cards because the
currently admitted runtime catalog is limited. A card must distinguish an
installed program from a retained installation record or an uninstalled example.
Open remains available only for committed programs.

Future catalog growth should use smaller icons and show more choices without
losing the selected-state clarity, the installed/not-installed distinction or
Deck readability. That denser catalog is deferred; it is not implied by the
present approval reference.
