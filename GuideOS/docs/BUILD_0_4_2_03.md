# GuideOS 0.4.2.03

Owner-approved design consolidation, 1 October 2026. Signed sequence 62, based on the freshly captured installed 0.4.2.02 / sequence 61 Seed. Retains the existing browser, audio, media cancellation and Play/Resume fixes.

Home now contains the enlarged 352 × 313 world window and an authored Planegotchi-style globe. The globe rotates once per 90 seconds with fixed lighting. Its 900 precomputed 144 × 144 frames are packed into 30 sheets; the renderer retains one sheet and one scaled current frame, with no simulation or image generation on the Deck. The shell updates the visible Home at 10 frames per second and stops Home updates when another screen owns the display.

The four shortcut slots initially show Files, Media, Browser and Settings, opening the existing destination routes. Select retains the tray visibility control. Left/right focuses shortcuts; up/down focuses the wheel. Right-stick wheel and L2/R2 behavior remain. This consolidates the approved preview choices as initial defaults; persistent user assignment of shortcut slots is a separate unfinished feature.

Borders and wheel spokes are suppressed, including the inner hub. Focus uses a brighter surface and slight enlargement. The selected shortcut grows approximately 5%; its pointer target follows its drawn bounds. Wheel focus brightens and enlarges its icon. Icons: Media uses an outlined right-facing Play triangle; Applications a thin PGRM badge; Browser bold www.; Storage a line-art hard drive; Nodes a broadcast antenna; Settings a crossed screwdriver and hammer.

The active V3 renderer uses a shared measured, clipped text component. Headings use 28 pixels, primary text 24, metadata/controls 20. Variable-name lists are full-width with four visible rows, and follow selection across the underlying model. Compact filenames retain a distinguishing tail and extension. The selected name gets three lines and scrolls within its fixed viewport when needed. The player has a full-width title area with stationary source/output/transport controls. File Details uses full-width stacked name, folder and other values rather than the narrow drawer. Long notices, titles and facts scroll without a reading deadline. Layout caching is bounded to 32 entries / 64 KiB. Complete values and action identities remain in the model.

Source verification: six layout/control tests passed under Linux with the Unicode provider; the prior media-transition inspection passed. Home, Media Library, Music Player and File Details source renders were reviewed. The package is checked against the captured Seed's trust and installed validator; the candidate image requires independent payload, whole-tree change-boundary, filesystem, and ARM64 renderer/import checks before writing.

Installation uses the fresh Seed capture and root-only writer. Boot, data and tail hashes must match the capture before and after the write; full root readback must match the candidate. Owner files, Wi-Fi credentials, Guide configuration, SSH identities and retained logs are compared before and after image construction. Installation receipts under `build/release-0.4.2.03/candidate` are the evidence of actual write status. Source checks and card readback do not establish physical boot, controller feel, performance or readability acceptance.

Design references: [text accommodation direction](DECK_TEXT_ACCOMMODATION_DIRECTION_0.md), [Home motion concept](../design/home-planet-motion/README.md), and the existing Figma file. Later Home/icon refinements are recorded in the local concept; Figma's tool-call limit prevented synchronizing those final refinements.
