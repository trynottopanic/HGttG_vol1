# GuideOS 0.4.2.04

Owner-directed correction of the three media layouts, 1 October 2026. Adapted by
visual analysis of the saved accepted draft image after the owner explicitly
requested proceeding without Figma. No Figma calls or paid-plan upgrade are
required. The reference image is a visual target, not a runtime bitmap.

## Presentation and controls

The active V3 renderer delegates Media Library, Music Player, File Details and
its complete metadata view to `guide_deck_layouts.py`. These views restore the
draft's pale blue field, light header/panels, dark slate rows, Noto Sans roles,
and amber focus marks. Home retains its accepted planet, wheel, shortcuts and
icons. Settings retains main headings with smaller explanations underneath.

Media Library displays four recording rows with source/format metadata and a
separate full-name panel. Refresh remains a working header button so it does not
consume a recording row. Catalogue pagination and complete action identities
are retained. Up/Down traverses the list and its commands; initial catalogue
focus selects the first recording when available.

Music Player has a full-width, two-line title panel; separate source/output
lines; a progress track; elapsed and total times at opposite ends; Previous,
Pause/Resume/Play and Next; a playback message; and fixed controller hints.
Unknown duration appears as `--:--`. A controls the primary transport regardless
of pointer focus. B returns through the launch history. Boundary transport
buttons are disabled rather than presenting actions with no adjacent recording.

File Details has separate Name and Folder panels, truthful format/size metadata,
and working Play, Copy and More details buttons. Duration is shown only when
provided. Unsupported Play and folder Copy are disabled and explained. Copy
continues to use an opaque storage entry identity. More details opens all facts
and returns to the summary, then to the selected file. Controller hints use
Left/Right for the horizontal buttons. Pointer targets use the drawn rectangles.

Long values scroll within bounded viewports with continuation indicators; controls
stay fixed. Two-line titles balance at measured word boundaries without changing
semantic values. The shell cache now repaints scrolling views even when the model
has not changed. Unicode coverage, glyph compositing and grayscale antialiasing
are verified to avoid colored text fringes on different backgrounds. Home's
independent renderer remains unchanged apart from a corrected update-notice box.
