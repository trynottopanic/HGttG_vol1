# GuideOS 0.4.3.02 — Browser containment and resident recovery

Owner-authorized source integration on 2 October 2026. Signed sequence 66.
The current image was written root-only to the freshly captured Seed on
3 October 2026. Full root readback and unchanged boot/data/tail checks passed.
It has not been booted or physically accepted after this write.

The [freeze investigation](BROWSER_FREEZE_0_4_3_01.md) established that PAM
migration bypassed launcher-only Browser limits. The
[memory and recovery policy](BROWSER_MEMORY_AND_RECOVERY_0.md) now applies the
ceiling to the actual Browser UID/session tree, reserves launch headroom,
protects resident control/recovery and logind/D-Bus, closes Browser under sustained
pressure, and adds bounded compressed RAM swap. Complete session cleanup precedes
display release. The kernel Image, boot assets and device trees are unchanged.

Start + Select extends the existing resident diagnostic overlay with active
applications and confirmed force-close/Home recovery. A confirms, B cancels or
resumes, Left/Right changes page. Display handoff precedes freezing; crash markers
precede pause. Power stays with logind and volume requests bypass the paused shell.

Browser now reuses the shared Guide text-entry model, renderer and stick controls
for addresses and selected webpage fields. X opens Address; select a webpage
field and use Y / Page keys to compose text, then choose Insert. B cancels.
Page drafts are masked, including ordinary fields; password and multiline input
use WebKit's literal text insertion. Opening on field focus is not implemented.
See [Browser integration](../apps/browser/gtk/INTEGRATION.md#shared-native-text-entry).

## Planegotchi revisions, 3 October

full-screen Planegotchi globe. The shell now routes trigger releases to the
viewer; the viewer owns bounded repeat timing and clears held state on suspension
or leaving the globe. The observable contract and cadence are recorded in the
[viewer controls](../apps/planegotchi/README.md). The current observer also includes
five illustrative static economic profiles, opened from existing regional
settlement marks. Each screen shows 13 sector shares, 90-day and average daily
output, population, food supply and external sales. Globe totals agree with the
five marks and 25,600 residents. Values and names are fixtures, not adopted lore
or simulated history. The portable simulation worker is not enabled or packaged.
The [review record](../design/planegotchi-static-economies-01/README.md) describes
the data and physical acceptance criteria.
