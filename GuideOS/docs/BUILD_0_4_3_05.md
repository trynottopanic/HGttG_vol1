# GuideOS 0.4.3.05: web browsing paused

On 3 October 2026 the owner directed that the current Browser integration be
removed from active use, with another engine considered later. The requested
automatic renderer comparison was abandoned before diagnostic code was added.

Home's wheel no longer contains Web Browser. Shortcut C now opens installed
Applications, using its existing icon; Files, Media and Settings retain their
shortcuts. Both the ordinary page menu and Browser controller are disabled,
including when the installed image still sets GUIDE_BROWSER=1. A stale browser
destination reports that web browsing is paused. The installed Browser service
entry refuses launch before runtime changes, Weston startup or WebKit import.
The old implementation remains in the workspace for later source work. The
subsequent offline Seed installation removes the Browser-exclusive dependencies
and masks its resident service, as recorded below.

The pending-update icon is 15 pixels high instead of 18, the nearest whole-pixel
reduction to 15%. Its upper stroke and dot are both four pixels wide, immediately
left of Wi-Fi. Planegotchi, native input, application assets and all other
unmodified payload files are preserved by SHA-256 comparison against signed .04.

## Essential verification

All 22 focused source checks passed under unprivileged WSL/Linux: retired
Browser routes/service entry, all Home wheel destinations, the Applications
shortcut, status-bar rendering, stale Wi-Fi actions and updated wheel order.
The tests run with GUIDE_BROWSER=1 to verify the old image setting cannot restore
the integration. Every packaged Python file compiled and the new signed archive
was independently verified against the trusted release key and installed base.
The full legacy suite and additional Browser experiments were not repeated.
These checks do not establish physical installation or acceptance.
