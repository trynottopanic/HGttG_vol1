## UI directions

Earlier theme specifications and draft images are retained as reference work.
They do not all describe the same interface revision. In particular,
[Field Theme 1's original frame](../GuideOS/THEME_FIELD_1.md#screen-regions)
reserves a control strip, while the
[handoff revision](../GuideOS/design/handoff/field-theme-1/THEME_FIELD_1.md#screen-regions)
removes a persistent strip. The adopted
[File Browser UI direction](../GuideOS/docs/FILE_BROWSER_UI_0.md) also omits a
permanent instruction bar. Use the relevant component contract and status when
working from these references.
