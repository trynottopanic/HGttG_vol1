# Desktop prototypes

These experiments exercise parts of the project's device and service contracts
on ordinary computers. They are reference implementations, not proof of complete
native Deck integration.

| Experiment | Purpose |
| --- | --- |
| [Continue on Deck](continue_on_deck_0/README.md) | Transfer an authorized video and verified playback-position record. |
| [Visiting Screen](visiting_screen_1/README.md) | Share one movie with an authorized television through a temporary host. |
| [Message Chime](message_chime_0/README.md) | Route one selected phone event to a local sound. |

Each component README contains its own setup, limits and focused checks. The
[handbook](../docs/HANDBOOK.md#prototype-scenarios) explains the intended behavior.
